TULL STORE — Telegram shop bot
================================

ФАЙЛЫ
- bot.py: Telegram-бот, каталог, заказы и админ-панель.
- requirements.txt: Python-зависимости.
- START_BOT.bat: запуск на Windows.
- START_BOT.sh: запуск на Linux/macOS.
- .env.example: пример локальных переменных (без действующего токена).

BOTHOST
1. Загрузите bot.py и requirements.txt в корень GitHub-репозитория.
   Можно также загрузить остальные безопасные файлы проекта.
2. В Bothost выберите Python 3.11, ветку main и команду запуска: python bot.py
3. В Bot Token вставьте НОВЫЙ токен от @BotFather.
4. Переменные окружения:
   DB_PATH=/app/data/shop.db
   RESERVE_MINUTES=30
   BOT_TOKEN задайте только если хостинг не передаёт токен через поле Bot Token.
5. Подключите постоянное хранилище к /app/data, если Bothost предлагает volume.

АДМИНИСТРАТОР
Единственный администратор: Telegram ID 8328202124.
Доступ к панели и административным командам есть только у этого ID.

ЦЕНЫ CLAUDE
Цены Claude Pro и Claude Max 5x по умолчанию не заданы (0), чтобы не
публиковать выдуманную стоимость. Администратор может установить их командами:
/setclaudeprice pro 1500
/setclaudeprice max5 7500
Вместо примеров укажите собственные цены в рублях.

ЗАЯВКИ CLAUDE
Бот запрашивает только Organization ID и создаёт заявку на ручную проверку.
Это НЕ подключает автоматически подписку. Сам по себе Organization ID
не является способом выдать личную подписку Claude Pro или Max.
Для управления участниками Claude Team/Enterprise официальные процедуры
Anthropic используют приглашение пользователя (обычно по email) и доступное
место в организации. Не обещайте покупателю активацию до фактического
подтверждения от Anthropic/владельца организации.
Официальная справка: https://support.claude.com/en/articles/13133750-manage-members-on-team-and-enterprise-plans

БЕЗОПАСНОСТЬ
- Не загружайте .env, токены, shop.db или пароли в публичный GitHub.
- Если токен когда-либо был показан на скриншоте/в чате, отзовите его в
  @BotFather командой /revoke и используйте новый.
- Не удаляйте базу данных shop.db и не меняйте DB_PATH без резервной копии.
- Добавляйте на склад только аккаунты, которые вы вправе передавать/продавать.
